# Disconnect the paired browser

Close the current connection while keeping the remembered peer.

## Steps

1. Open Beam me up on either connected profile.
2. Click **Disconnect**.
3. **Eat:** neither browser is connected, but the remembered peer and **Connect to paired browser** remain available. No new code is required to reconnect.

Disconnect also invalidates active transfer work. It does not sign out a successfully transferred Slack session.

To remove trust instead, [forget the paired browser](forget-paired-browser.md).
